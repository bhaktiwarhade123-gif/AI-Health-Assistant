# AI Health Assistant

## Project Overview

AI Health Assistant is a web-based health assistance chatbot developed using Python and Flask. It provides basic information related to common health conditions through an interactive chat interface.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript

## Features

* Interactive chatbot interface
* User-friendly web interface
* Basic health-related information
* Speech-to-text functionality
* Text-to-speech functionality
* Flask-based web application

## Health Conditions Covered

The project provides basic information for conditions such as:

* Common Cold
* Flu
* Migraine

## How to Run

1. Install Python.
2. Install Flask:

```bash
pip install flask
```

3. Open the project folder in VS Code or Command Prompt.
4. Run:

```bash
python app.py
```

5. Open the localhost URL shown in the terminal in your browser.
